# Opis projektu

Projekt dotyczy aplikacji umożliwiającej rezerwowanie miejsc parkingowych na terenie uczelni.

## Problem
Brak wolnych miejsc i chaos podczas parkowania w godzinach szczytu.

## Odbiorcy
Studenci i pracownicy uczelni dojeżdżający samochodem.

## Główne funkcje
- sprawdzanie dostępności miejsc
- rezerwacja miejsca na określony czas
- potwierdzenie rezerwacji
