# Inspiracje

## Inspiracje i skojarzenia
- parking uczelni
- brak miejsc
- godziny szczytu
- stres przed zajęciami
- rezerwacja online
- dostępność w czasie rzeczywistym

## Elementy projektu
- ekran logowania użytkownika
- widok mapy lub listy miejsc parkingowych
- system rezerwacji miejsca na określony czas
- informacje o dostępności miejsc

## Wstępne dane wejściowe
- lista parkingów na terenie uczelni
- lista miejsc parkingowych
- lista użytkowników
- lista dostępnych godzin rezerwacji

## Źródła pomysłu
- własne doświadczenia z parkowaniem na uczelni
- obserwacja problemów studentów i pracowników
- rozmowy ze znajomymi dojeżdżającymi samochodem
